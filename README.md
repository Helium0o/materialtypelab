# materialtypelab

A **Material** workspace and **effect maps** for TypeLab, in the style of Material Maker. Node graphs make seamless PBR materials, and they also join TypeLab's effects, filters, dither, blends, masks, layers, patterns and materials into one effect.

- **For the TypeLab session:** paste [`PROMPT-FOR-TYPELAB.md`](PROMPT-FOR-TYPELAB.md), then read [`HANDOFF-TYPELAB.md`](HANDOFF-TYPELAB.md).
- **The code:** [`typelab-material/`](typelab-material/README.md). Install steps are in [`INSTALL.md`](typelab-material/INSTALL.md).
- **Everything in one zip:** [`typelab-material-package.zip`](typelab-material-package.zip).
- **Background:** [`handover/`](handover/MATERIAL-WORKSPACE-HANDOVER.md) has the original plan and the reference screenshots.
